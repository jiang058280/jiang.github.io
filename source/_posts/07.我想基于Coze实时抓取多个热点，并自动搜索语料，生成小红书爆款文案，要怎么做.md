### 一、整体思路

将“热点抓取→语料搜索→文案生成→排版输出”四个环节串联成一个自动化工作流。搭建完成后，只需输入一个主题（如“AI”或“护肤”），工作流就能自动完成素材搜索、文案撰写、图片设计到标签优化的全流程。

### 二、热点抓取：获取实时话题

热点抓取是第一步，决定了文案的时效性。

**方案一：使用官方新闻插件（推荐）**
- 在插件市场搜索添加“**头条新闻**”或“**36氪**”插件。
- 关键参数配置：
  - `searchWord`：填入你感兴趣的关键词（如“AI”“科技”“护肤”）
  - `pageSize`：设置50~100，数值越大获取信息越多但耗时更长
  - `sort`：填0表示按时间排序，获取最新新闻

**方案二：使用RSS订阅源**
- 添加“RSS解析器”插件，订阅虎嗅、36氪、量子位等科技媒体RSS源。

**方案三：使用第三方百度搜索插件**
- 若官方插件无法满足需求，可导入开源百度搜索插件（GitHub: coze_baidu_search），配置`query`和`num`（建议5-8条）参数。

### 三、语料搜索：自动搜集写作素材

光有热点标题不够，还需要搜索相关背景资料作为文案的事实支撑。

- 在热点抓取节点后，添加“**头条搜索**”插件节点。
- 输入参数引用开始节点的`subject`变量作为搜索关键词。
- 设置`count`为10，获取足够的相关文章和资讯。
- 搜索结果的`data`会输出包含标题和正文片段的信息，供后续大模型引用。

> **关键点**：搜索环节解决了AI“瞎编”的问题——用真实素材支撑文案，避免内容空洞。

### 四、文案生成：大模型仿写爆款

这是工作流的“大脑”环节，决定文案质量。

**① 添加大模型节点**
- 点击“添加节点”→选择“大模型”。
- 模型推荐：豆包·2.0·Pro 或 Kimi-128k（Kimi对文案创作较好）。
- 将上一步搜索到的素材作为输入变量引用。

**② 配置系统提示词**

```markdown
# 角色
你是一个小红书爆款文案生成助手，专攻通过自动化流程快速批量产出小红书爆款文案，熟悉小红书平台算法逻辑、用户偏好及流量密码。

# 技能
1. 信息抓取：接收用户提供的主题和搜索素材后，快速提取核心要素，明确文案主题、风格倾向（干货型/种草型/搞笑型/励志型）、核心卖点及目标场景。
2. 平台适配：精准匹配小红书“开头抓眼球-中间有记忆点-结尾强互动”黄金结构，自动适配手机端竖排阅读习惯（每段≤2行，用「」「❗」「」等符号分隔重点）。
3. 批量产出：单次请求自动生成3篇高质量差异化文案。
```

**③ 用户提示词**
```
主题：{{开始节点.subject}}
参考素材：{{搜索节点.data}}
字数要求：{{开始节点.word_count}}
请按小红书爆款风格生成标题、正文和标签。
```

### 五、封面文案提取与配图生成

**① 封面文案提取**
- 再添加一个大模型节点，将正文文案作为输入。
- 提示词要求提取：
  - `title`：封面主标题（不超过12字）
  - `subtitle`：副标题（10-20字）
  - `decorative_text`：点缀性文案（10-20字）
  - `tags`：相关标签（4-5个，格式：#标签1 #标签2）

**② 配图提示词生成**
- 根据主题和文案内容，让大模型生成详细的文生图提示词（中文，细节丰富）。
- 使用“图像生成”节点（如Seedream 4.0），尺寸设置为682x1024（小红书竖屏比例）。

### 六、画板排版与输出

**① 画板节点排版**
- 添加“画板”节点。
- 将生成的图片作为背景，封面文案（主标题、副标题等）拖入画板对应位置。
- 画板支持自由设计样式，可预设模板实现自动化排版。

**② 结束节点输出**
- 输出完整的文案（含标题、正文、标签）和排版后的图片。
- 可直接复制发布到小红书。

### 七、完整工作流节点概览

| 序号 | 节点              | 功能                                              |
| ---- | ----------------- | ------------------------------------------------- |
| 1    | 开始节点          | 定义输入变量：subject（主题）、word_count（字数） |
| 2    | 热点抓取（插件）  | 获取实时热点新闻（头条新闻/36氪）                 |
| 3    | 语料搜索（插件）  | 搜索主题相关背景资料                              |
| 4    | 大模型·文案生成   | 根据素材仿写小红书爆款文案                        |
| 5    | 大模型·封面提取   | 提取主标题、副标题、点缀文案、标签                |
| 6    | 大模型·生图提示词 | 生成详细的文生图指令                              |
| 7    | 图像生成          | 生成配图（尺寸682x1024）                          |
| 8    | 画板节点          | 图文自动排版合成                                  |
| 9    | 结束节点          | 输出完整图文                                      |

### 八、进阶优化建议

1. **多热点批量处理**：使用“批处理”节点，循环处理多个热点关键词，一次产出多篇文案。
2. **定时触发**：设置定时任务，每天早上自动抓取当日热点并推送。
3. **飞书同步**：将生成的文案自动存入飞书多维表格，建立爆款文案库。
4. **违禁词检测**：在文案生成后增加“违禁词检测”节点，确保内容合规。
