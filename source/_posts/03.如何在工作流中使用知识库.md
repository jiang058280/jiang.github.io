在工作流中使用知识库的核心是通过“知识库检索节点”将外部文档数据与LLM结合，实现检索增强生成（RAG）。典型流程为：开始节点定义用户输入（如query）→ 知识库检索节点根据输入从指定知识库召回相关内容 → 大模型节点将用户问题与检索结果拼接，生成最终回答 → 结束节点输出答案。知识库需提前创建并上传文档（支持PDF、Word、TXT等），Coze自动完成文本分块和向量化存储。使用要点：Query必须引用上游节点输出，知识库类型选择“扣子知识库”，大模型系统提示词应强制约束“仅基于知识库回答”。

### 一、知识库节点类型与功能

Coze工作流中知识库相关节点分为两类：

| 节点类型           | 功能                                                         |
| ------------------ | ------------------------------------------------------------ |
| **知识库检索节点** | 根据用户输入从关联知识库中召回最匹配的数据并返回，是智能知识调用的核心 |
| **知识库写入节点** | 将新文档或文本内容添加到指定知识库，实现知识的自动化更新     |

### 二、使用知识库检索节点的步骤

**前提**：在工作流中使用知识库前，需先在Coze平台左侧菜单栏选择“知识库”，创建并上传文档（支持PDF、Word、Markdown、TXT、Excel等多种格式）。

**完整配置流程**：

1. 创建工作流后，点击开始节点配置输入参数（如变量名设为`query`）
2. 点击开始节点右侧“+”号，选择**知识库检索节点**
3. 点击新增的知识库检索节点，配置：
   - **Query变量值**：引用上游节点输出，如`开始.query`
   - **知识库**：点击右侧“+”按钮，选择已创建的知识库
4. 在知识库检索节点后接**大模型节点**，将开始节点的问题和知识库检索结果作为输入
5. 配置大模型的系统提示词，强制约束“根据问题和背景知识给出合理答复”
6. 连接结束节点，输出最终结果

### 三、核心参数说明

**知识库检索节点关键配置**：

| 参数           | 说明                                                 |
| -------------- | ---------------------------------------------------- |
| **搜索策略**   | 混合（通用首选）、语义（跨语言）、全文（精准关键词） |
| **最大召回数** | 默认5条，控制返回的文档片段数量                      |
| **最小匹配度** | 默认0.5，低于此阈值的文档不被召回                    |
| **查询改写**   | 默认开启，提升意图捕捉效果                           |
| **结果重排**   | 高精度场景推荐开启                                   |

### 四、高级功能：知识库写入节点

知识库写入节点用于构建**自动化知识更新系统**，让知识库能够动态生长。核心特性：

- 单次仅传1个文件，多文件需用批处理/循环节点
- **异步节点**：工作流投递完文件后继续执行后续步骤，无需等待完全处理完毕
- 输出参数：`documentId`（文档唯一ID）、`fileName`（文档名称）、`fileUrl`（访问地址）

典型应用场景：
- 定时爬取行业资讯自动存入知识库
- 阅读到有价值文章时，通过智能体自动整理入库
- 企业文档更新后，自动同步到客服机器人知识库

### 五、典型工作流拓扑

```text
开始节点(用户输入问题) 
    ↓
知识库检索节点(根据Query召回相关文档片段)
    ↓
大模型节点(拼接用户问题+检索结果，生成回答)
    ↓
结束节点(输出最终答案)
```



### 六、最佳实践与注意事项

| 要点                         | 说明                                                         |
| ---------------------------- | ------------------------------------------------------------ |
| **提示词强制约束**           | 系统提示词应写明“仅基于知识库回答，若无匹配则告知用户不清楚”，防止模型自行发挥 |
| **文档质量**                 | 文档内容需与服务场景高度匹配，不相关内容宁可不放，避免干扰检索结果 |
| **文档格式**                 | 尽量结构化，FAQ形式问答文档通常比大段叙述文本检索效果更好    |
| **知识库检索 vs 大模型节点** | 检索节点100%触发知识库调用（开发者控制）；大模型节点由模型自主判断是否调用 |
| **调试技巧**                 | 可通过输出节点提前查看知识库查询结果，便于排查问题           |
