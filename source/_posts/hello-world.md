欢迎来到我的博客！这是第一篇文章。

## 这个博客是怎么搭起来的

- 生成器：[Hexo](https://hexo.io)
- 主题：[Butterfly](https://github.com/jhx0/hexo-theme-butterfly)
- 托管：GitHub Pages，免费域名 `jiang058280.github.io`
- 部署：git push 后由 GitHub Actions 自动构建发布

## 以后怎么写新文章

1. 在 `source/_posts/` 下新建一个 Markdown 文件（或运行 `npm run new 文章标题`）
2. 写完保存，提交并推送：

```bash
git add .
git commit -m "feat: 新文章"
git push
```

3. 等 1-2 分钟，网站自动更新。
