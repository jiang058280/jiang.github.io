## <font color="red">问题: Python 语言特性：强类型与动态类型</font>

<details>
<summary><b style="font-size: 1.5rem; color: #2c6b8f;">👇 点击展开/折叠 面试背诵模板（建议先背这个）</b></summary>
	<mymark>
强类型指变量绑定具体类型后，不同类型之间不会发生隐式类型转换，类型错误会在运行时抛出 TypeError（如 "1" + 1 报错）。动态类型指变量本身不绑定类型，可以在运行时随时指向不同类型的对象（如 a = 1; a = "hello" 合法）。Python 是强类型动态语言：变量类型在赋值时确定，且在运行时可以改变，但操作时必须遵循类型规则。与之对比：弱类型如 JavaScript 支持隐式转换（"1" + 1 = "11"），静态类型如 Java 需编译期声明类型且不可变。有人认为:python变量不用声明类型，可以随便换类型所以认为是弱类型,这样的理解是不准确的,随便换类型是动态类型特征，和强弱无关。
    </mymark>
</details>

### 强类型 vs 弱类型（类型安全性角度）

| 维度         | 强类型（Python）      | 弱类型（JavaScript）       |
| ------------ | --------------------- | -------------------------- |
| 隐式类型转换 | ❌ 不允许              | ✅ 自动转换                 |
| 类型错误时机 | 运行时抛出 TypeError  | 静默处理或隐式转换         |
| 典型示例     | `"1" + 1` → TypeError | `"1" + 1` → `"11"`         |
| 安全性       | 更安全，减少意外行为  | 灵活，但易产生难排查的 bug |

### 动态类型 vs 静态类型（类型绑定时机角度）

| 维度         | 动态类型（Python）         | 静态类型（Java）   |
| ------------ | -------------------------- | ------------------ |
| 类型检查时机 | 运行时                     | 编译期             |
| 变量类型绑定 | 赋值时动态确定，可随时改变 | 声明时固定，不可变 |
| 类型声明     | 无需声明（或可选注解）     | 必须显式声明       |
| 灵活性       | 高，代码简洁               | 低，需严格类型约束 |

```python
# 动态类型：变量可以随时改变类型
a = 1          # int
a = "hello"    # 现在变成 str，完全合法
```

```java
// 静态类型：类型一旦声明不可变
int a = 1;     // 必须声明类型
a = "hello";   // ❌ 编译错误：类型不匹配
```

### Python 类型注解（Type Hints）—— 并非静态类型

Python 3.5+ 支持类型注解（如 `def add(a: int, b: int) -> int:`），但**仅在运行时被忽略**（不会触发编译期检查），本质是给开发工具（如 PyCharm、mypy）提供提示。这并不改变 Python 的动态类型本质，仅提升代码可读性和辅助静态分析。

```python
def greet(name: str) -> str:   # 注解仅作提示，运行时不强制
    return "Hello " + name

greet(123)   # 运行时不报错（除非内部操作报错），但 mypy 会告警
```

### 三组概念交叉对比表

| 语言       | 类型检查时机   | 类型安全性 | 典型示例                 |
| ---------- | -------------- | ---------- | ------------------------ |
| Python     | 运行时（动态） | 强类型     | `"1" + 1` 报错           |
| JavaScript | 运行时（动态） | 弱类型     | `"1" + 1` → `"11"`       |
| Java       | 编译期（静态） | 强类型     | `"1" + 1` 报错（需转型） |
| C          | 编译期（静态） | 弱类型     | 指针可任意强转，极易出错 |
