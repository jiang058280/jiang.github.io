## <font color="red">问题: 零样本、少样本和思维链提示三者的核心区别</font>

<details>
<summary><b style="font-size: 1.5rem; color: #2c6b8f;">👇 点击展开/折叠 面试背诵模板（建议先背这个）</b></summary>
	<mymark>
零样本提示（Zero-shot）直接给出任务指令，不提供任何示例，依赖模型预训练知识理解并执行任务。少样本提示（Few-shot）在指令后附加 2-5 个输入输出示例，通过上下文学习让模型快速适配任务模式。思维链提示（Chain-of-Thought, CoT）要求模型在输出最终答案前，显式展示逐步推理过程，适用于需要逻辑推导的复杂任务。三者核心区别在于：零样本最简洁但精度较低；少样本通过示例提升准确性但需精心设计；思维链通过推理过程增强复杂问题的可靠性，通常与零样本或少样本结合使用。
    </mymark>
</details>

### 三者对比速览表

| 维度       | 零样本提示                         | 少样本提示                       | 思维链提示                             |
| ---------- | ---------------------------------- | -------------------------------- | -------------------------------------- |
| 示例数量   | 0 个                               | 2-5 个                           | 可有可无（常与少样本结合）             |
| 推理步骤   | 直接输出结果                       | 直接输出结果                     | 显式要求分步推理                       |
| 适用任务   | 简单问答、常识、分类               | 格式要求严格、特定风格、简单逻辑 | 数学题、多步推理、复杂决策             |
| 对模型要求 | 基本指令遵循能力                   | 上下文学习能力                   | 较强的推理和指令遵循能力               |
| 性能特点   | 最快、成本最低，但复杂任务可靠性低 | 较高准确性，但示例质量影响大     | 在复杂推理上准确率显著提升，但输出更长 |

### 典型应用示例对比

**零样本**：
```
请将以下句子翻译成英文：“今天天气很好。”
```

**少样本**：
```
将以下句子翻译成英文。
示例：
“你好” → “Hello”
“谢谢” → “Thank you”
“再见” → “Goodbye”
“今天天气很好。” →
```

**思维链（零样本 CoT）**：
```
李明有 5 个苹果，他又买了 3 个，然后吃了 2 个。请问他剩几个？请分步思考。
```

**思维链（少样本 CoT）**：
```
示例1：小明有 4 本书，借出 1 本，又买 2 本。结果？ 4-1+2=5，所以剩 5 本。
示例2：……
现在：李明有 5 个苹果，又买 3 个，吃 2 个。结果？请分步计算。
```

### 选择建议

- **简单、通用任务**（翻译、摘要、分类）→ **零样本**，先试再优化。
- **格式敏感、需要特定风格或输出结构** → **少样本**，示例能有效约束输出。
- **多步推理、数学逻辑、因果关系分析** → **思维链**，尤其当零样本失败时，加上“请分步思考”往往能显著提升效果。
- **复合场景**：先少样本提供格式，再要求思维链给出推理，可兼顾格式和逻辑。
