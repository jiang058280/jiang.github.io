Coze 知识库检索节点的参数主要分为**输入、检索策略、召回控制、优化功能**等几个方面。以下是各参数的具体说明：

### 核心输入参数

| 参数       | 说明                                                         | 是否必填 |
| :--------- | :----------------------------------------------------------- | :------- |
| **Query**  | 用户在知识库中检索的关键信息。该参数为 `String` 类型，通常需要引用上游节点（如“开始”节点）的输入。 | 是       |
| **知识库** | 指定要检索的目标知识库。必须先关联一个已创建的知识库，才能配置其他召回参数。 | 是       |

---

### 检索策略

| 参数            | 说明                                                         |
| :-------------- | :----------------------------------------------------------- |
| **搜索策略**    | 决定系统如何查找答案。提供三种策略：<br>- **混合**：结合全文和语义检索，是容错率最高、最通用的默认策略。<br>- **语义**：基于语义理解，适合用户提问灵活、需跨语言或理解深层意图的场景。<br>- **全文**：严格匹配关键词，适合检索专有名词、ID、缩写等精确内容。 |
| **表格SQL查询** | 默认开启。当知识库包含表格数据时，系统会自动将用户问题转为SQL查询，精准检索表格内容。 |

---

### 召回控制

| 参数             | 说明                                                         |
| :--------------- | :----------------------------------------------------------- |
| **最大召回数量** | 控制从知识库返回的最大文档片段数。默认值为5条。设置值越大信息越全，但噪声也可能增多。建议根据知识库内容质量设置在3-8条之间。 |
| **最小匹配度**   | 设置知识库片段与问题的相似度阈值。默认值为0.5。只有高于此值的片段才会被召回。建议设置在0.5-0.6之间以平衡召回率与准确率。 |

---

### 优化功能

| 参数         | 说明                                                         |
| :----------- | :----------------------------------------------------------- |
| **查询改写** | 默认开启。在多轮对话中，根据对话历史自动优化用户问题，使其意图更清晰。开启后会增加Token消耗和延迟。 |
| **结果重排** | 高精度场景推荐开启。对召回的多个结果进行重新排序，将最相关的信息排在前面。 |
| **会话历史** | 可开启。开启后会利用多轮对话历史提升检索相关性，但轮数越多Token消耗越大。 |
| **权限控制** | 即“仅查看个人文档”。默认关闭，开启后检索范围将仅限于当前用户自己上传的内容。 |
