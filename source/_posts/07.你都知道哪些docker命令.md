## <font color="red">问题: Docker的常用命令有哪些？</font>

Docker命令按功能分类为镜像管理（docker pull/push/images/build/rmi/tag）、容器管理（docker run/ps/start/stop/restart/rm/exec/logs/inspect）、网络管理（docker network create/ls/connect/disconnect）、卷管理（docker volume create/ls/rm/inspect）及系统管理（docker info/version/system prune）。核心高频命令为docker run（创建并运行容器）、docker ps（查看容器状态）、docker images（查看镜像列表）、docker exec（进入容器执行命令）、docker logs（查看容器日志）。建议通过`docker command --help`查看命令帮助。

### 一、镜像管理命令

| 命令            | 作用                    | 示例                               |
| --------------- | ----------------------- | ---------------------------------- |
| `docker pull`   | 从镜像仓库拉取镜像      | `docker pull nginx:latest`         |
| `docker push`   | 将镜像推送到远程仓库    | `docker push myrepo/nginx:v1`      |
| `docker images` | 列出本地所有镜像        | `docker images`                    |
| `docker build`  | 根据Dockerfile构建镜像  | `docker build -t myapp:1.0 .`      |
| `docker rmi`    | 删除本地镜像            | `docker rmi nginx:latest`          |
| `docker tag`    | 为镜像打标签            | `docker tag nginx myrepo/nginx:v1` |
| `docker save`   | 将镜像导出为tar归档文件 | `docker save -o nginx.tar nginx`   |
| `docker load`   | 从tar文件导入镜像       | `docker load -i nginx.tar`         |

### 二、容器管理命令

| 命令                        | 作用                       | 示例                                        |
| --------------------------- | -------------------------- | ------------------------------------------- |
| `docker run`                | 创建并启动容器（最常用）   | `docker run -d -p 8080:80 --name web nginx` |
| `docker ps`                 | 列出运行中的容器           | `docker ps`（加`-a`显示所有容器）           |
| `docker start/stop/restart` | 启动/停止/重启容器         | `docker stop web`                           |
| `docker rm`                 | 删除已停止的容器           | `docker rm web`                             |
| `docker exec`               | 在运行中的容器内执行命令   | `docker exec -it web /bin/bash`             |
| `docker logs`               | 查看容器日志               | `docker logs -f web`                        |
| `docker inspect`            | 查看容器或镜像的详细信息   | `docker inspect web`                        |
| `docker cp`                 | 在容器和宿主机之间复制文件 | `docker cp web:/app/logs ./logs`            |
| `docker commit`             | 将容器保存为新镜像         | `docker commit web myweb:v2`                |

### 三、网络管理命令

| 命令                        | 作用             | 示例                                  |
| --------------------------- | ---------------- | ------------------------------------- |
| `docker network create`     | 创建自定义网络   | `docker network create mynet`         |
| `docker network ls`         | 列出所有网络     | `docker network ls`                   |
| `docker network connect`    | 将容器连接到网络 | `docker network connect mynet web`    |
| `docker network disconnect` | 将容器从网络断开 | `docker network disconnect mynet web` |
| `docker network inspect`    | 查看网络详细信息 | `docker network inspect mynet`        |
| `docker network rm`         | 删除网络         | `docker network rm mynet`             |

### 四、卷管理命令

| 命令                    | 作用           | 示例                          |
| ----------------------- | -------------- | ----------------------------- |
| `docker volume create`  | 创建数据卷     | `docker volume create myvol`  |
| `docker volume ls`      | 列出所有卷     | `docker volume ls`            |
| `docker volume inspect` | 查看卷详细信息 | `docker volume inspect myvol` |
| `docker volume rm`      | 删除卷         | `docker volume rm myvol`      |

### 五、系统管理命令

| 命令                  | 作用                                       | 示例                     |
| --------------------- | ------------------------------------------ | ------------------------ |
| `docker info`         | 查看Docker系统信息                         | `docker info`            |
| `docker version`      | 查看Docker版本                             | `docker version`         |
| `docker system prune` | 清理未使用的资源（镜像、容器、网络、缓存） | `docker system prune -a` |
| `docker stats`        | 查看容器资源使用统计（CPU、内存等）        | `docker stats`           |
| `docker events`       | 实时监听Docker事件流                       | `docker events`          |

### 六、常用命令组合技巧

| 场景               | 命令组合                                                     |
| ------------------ | ------------------------------------------------------------ |
| 清理所有已停止容器 | `docker container prune`                                     |
| 删除所有无用镜像   | `docker image prune -a`                                      |
| 停止并删除所有容器 | `docker stop $(docker ps -aq) && docker rm $(docker ps -aq)` |
| 进入容器调试       | `docker exec -it <容器名> /bin/bash`                         |
| 查看容器实时日志   | `docker logs -f --tail 100 <容器名>`                         |

### 七、命令速记要点

- **`docker run`** 是最核心的命令，参数最多（`-d`后台运行、`-p`端口映射、`-v`挂载卷、`--name`命名、`--network`指定网络、`-e`环境变量）
- **`docker ps -a`** 查看所有容器（包含已停止的）
- **`docker exec -it`** 是进入容器最常用的方式
- **`docker logs -f`** 实时追踪日志输出
- **`docker system prune`** 定期清理释放磁盘空间
- 不记得参数时用 `docker command --help` 查看帮助
