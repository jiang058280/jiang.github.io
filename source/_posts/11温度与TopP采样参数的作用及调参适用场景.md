	<mymark>
温度（Temperature）和 Top-P 是控制大语言模型生成随机性和多样性的核心采样参数。温度通过缩放 logits 的概率分布，影响 token 选择的平滑度：温度越低（趋近0），分布越尖锐，模型倾向选择最高概率 token，输出更确定性、更保守；温度越高（如1.0以上），分布越平滑，低概率 token 被选中的机会增加，输出更随机、更具创意。Top-P（核采样）则动态选择概率质量累计达到 P 的最小 token 集合，在此集合内重新归一化采样，控制候选池大小。两者常协同使用：低温度（0.1-0.3）+ 低 Top-P（0.5-0.8）适用于事实性、严谨任务；高温度（0.8-1.2）+ 高 Top-P（0.9-1.0）用于创意写作、头脑风暴等需多样性的场景。

### 一、温度（Temperature）的作用机制

**数学本质**：温度参数 T 应用于 softmax 函数的缩放因子：`P_i = exp(z_i / T) / Σ exp(z_j / T)`。当 T=1 时，保持原始概率分布；T<1 时，较大概率的 token 被放大，较大概率差异导致分布更尖锐；T>1 时，概率差异被压缩，分布更平坦。

**调参效应**：
- **T → 0**：趋于确定性（贪心解码），几乎每次输出相同，适合答案唯一的事实问答、代码生成、数学推导。
- **T = 0.1~0.5**：低随机性，输出稳定但有轻微变化，适合需要一致性的翻译、摘要、格式输出。
- **T = 0.7~1.0**：平衡创造性与可靠性，适合通用对话、内容生成。
- **T > 1.0**：高随机性，可能产生意外或荒谬内容，适合创意写作、头脑风暴。

### 二、Top-P（核采样）的作用机制

**数学本质**：按概率从高到低对 token 排序，取累计概率达到 P 的最小集合 S，然后从 S 中重新归一化采样。例如 P=0.9，则取前若干个 token，使其概率之和刚好超过0.9，排除尾部大量低概率 token。

**调参效应**：
- **P=1.0**：不截断，考虑所有 token（等同于完整分布采样），多样性最大，风险最高。
- **P=0.9~1.0**：保留绝大多数合理候选，适用于创意任务。
- **P=0.5~0.8**：截断较多候选，集中于高概率区域，输出更集中、更可控。
- **P<0.5**：极度压缩候选空间，几乎仅保留最确定 token，适合严格事实性任务。

### 三、协同调参策略与典型配置矩阵

| 任务类型           | 温度（T） | Top-P      | 效果                       |
| ------------------ | --------- | ---------- | -------------------------- |
| 事实问答、知识检索 | 0.0 ~ 0.1 | 0.1 ~ 0.5  | 输出确定、准确，幻觉率低   |
| 代码生成、SQL生成  | 0.0 ~ 0.3 | 0.5 ~ 0.8  | 语法正确性高，少量变化     |
| 文本摘要、翻译     | 0.3 ~ 0.5 | 0.7 ~ 0.9  | 忠实原文，适度流畅         |
| 通用对话助手       | 0.7 ~ 0.9 | 0.8 ~ 0.95 | 自然、多样化且合理         |
| 创意写作、故事生成 | 0.9 ~ 1.3 | 0.9 ~ 1.0  | 出人意料，富有想象力       |
| 头脑风暴、变体生成 | 1.0 ~ 1.5 | 0.95 ~ 1.0 | 最大多样性，可接受偶尔离题 |

### 四、实践调参原则与误区

- **优先调温度，再调 Top-P**：温度影响整体“确定性”，Top-P 影响候选池大小。先从温度开始，若输出仍单调则适当提高 Top-P。
- **避免两者同时极端**：T 极低 + P 极低会过度压缩输出，导致重复性语段或死循环；T 极高 + P 极高可能产生无意义内容。
- **输出长度影响**：短文本可容忍更高随机性，长文本需更低温度保证连贯性。
- **不同模型迁移时需重新校准**：不同模型对相同参数的反应差异很大（如 GPT-4 对温度更敏感），不能直接复现。
- **稳定性优先场景**：建议设置 T=0.0 或 0.1，配合重复惩罚（Frequency/Presence Penalty）进一步减少重复，而不是靠 Top-P 控制。
