# TACHYON Total Security 4.0 · AI智能助理模块 · 面试项目资料


## 一、项目概述（一句话定位）

**TACHYON Total Security 4.0（TTS）** 是公司面向企业客户的终端安全统一管理平台，包含防病毒、防火墙、策略管控、日志审计等核心能力。本次我负责的是 **TTS平台的AI能力升级——AI智能助理模块**，旨在解决企业客户在安全管理中面临的 **客服响应慢、问题分流难、知识复用低、新人培训成本高** 等痛点。


## 二、项目背景（母体产品与升级动因）

### 2.1 TTS 产品简介（严格依据文档）

TACHYON Total Security 4.0 由以下核心组件构成：

| 组件                         | 功能                                                    |
| :--------------------------- | :------------------------------------------------------ |
| **TTSC（管理控制台）**       | 提供Web管理页面，统一管理安全策略、监控仪表盘、日志审计 |
| **TA（TACHYON Agent）**      | 安装在用户PC/Server上，接收策略、执行安全指令           |
| **TES（Endpoint Security）** | 终端防病毒引擎（实时/基础/精密/预定扫描）               |
| **TSS（Server Security）**   | 服务器防病毒引擎                                        |
| **防火墙模块**               | 入侵防御、程序认证、网站/共享文件夹阻断                 |
| **自我保护模块**             | 文件/注册表/进程保护                                    |

该产品的典型企业客户拥有 **客服人员约10人、技术人员约20人、售后人员约4人**，通过TTS管理内部数百台终端的安全状态。

### 2.2 本次升级动因（业务痛点）

在对已部署TTS的企业客户进行回访和需求调研中，发现客户普遍存在以下 **服务侧痛点**：

| 序号 | 客户痛点（基于真实反馈）                                     |
| :--: | :----------------------------------------------------------- |
|  1   | 问题高发期排队时间长，客服回复慢                             |
|  2   | 客服对各类技术问题不了解，无法判断类型并正确分配给对应技术人员 |
|  3   | 培养新人客服时间成本高，还需专门分配老员工进行培训           |
|  4   | 聊天记录零散，无法自动统计高频问题、产品缺陷等               |
|  5   | 服务质量多依赖个人情绪、经验和疲劳度，波动大，无法标准化     |
|  6   | 普通智能客服只能回复简单固定知识库问题，无法从专业角度应答，且人工维护知识库成本高 |

**核心决策**：公司决定对TTS平台进行 **AI能力升级**，首期落地 **AI智能助理（客服优化方向）** 模块，我作为该模块的负责人。


## 三、本次AI升级内容（重点描述）

### 3.1 升级定位

**“AI智能体前置分流 + 人工客服兜底”** 双轨模式：

> AI承接全部重复性、基础性咨询；将复杂投诉、技术操作问题、非标准化问题自动识别并转接对应人工。

### 3.2 核心功能模块（完整描述）

| 功能模块                   | 具体能力                                                     | 对应解决痛点 |
| :------------------------- | :----------------------------------------------------------- | :----------- |
| **① 智能检索与知识库闭环** | 优先检索TTS知识库应答，未命中问题自动标记汇总，供决策是否录入 | 痛点1、6     |
| **② 技术问题自动分流**     | 大模型判断问题类型（防病毒/防火墙/策略/安装等），自动创建工单指派给对应技术人员 | 痛点2        |
| **③ 人工无缝兜底**         | 非标准/复杂问题自动转接人工客服，系统同步推送上下文摘要与建议方案 | 痛点1        |
| **④ 客户情绪安抚**         | 识别投诉/负面情绪关键词，触发安抚话术并秒级转接高级人工，避免矛盾升级 | —            |

### 3.3 技术架构（面试表述用）

| 层级               | 技术实现                                                     |
| :----------------- | :----------------------------------------------------------- |
| **智能分流层**     | 基于大语言模型进行语义理解与意图分类，将用户问题分为“基础咨询/技术操作/投诉情绪/非标准”四类并执行路由 |
| **知识检索层**     | 构建TTS产品的FAQ与SOP知识库（涵盖防病毒策略配置、防火墙规则、安装部署等场景），支持关键词+语义混合检索 |
| **文档自动生成层** | 利用大模型文本生成能力，将人工处理步骤自动提取、结构化，生成标准化解决方案文档入库 |
| **工单分配层**     | 对接企业内部工单系统，大模型判断问题类型后自动创建工单并指派至对应技术负责人 |
| **客服工作台**     | 面向人工客服的统一界面，展示AI预填的答复建议、客户情绪标签、问题分类建议，支持一键转接 |
| **数据看板**       | 集成TTS现有日志体系，统计高频问题、未命中知识、客服效率等    |

> **核心技术依赖**：大语言模型（意图识别/分类/情绪判断/方案生成）、知识库管理系统、TTS现有日志与工单接口。

### 问题流转效率
- 过去转接一个技术问题需耗时 **5~10分钟** 沟通找人

### 知识复用效率
- 无需设置专人维护知识库
- 10名客服 + 6名技术人员在 **日常处理问题中顺带完成知识库建设**

### 综合人效
- **同样18人，可承接的业务量约为之前的1.5倍**
- 客服从“复读机”变为“问题终结者”，技术人员从“客服支援”回归“产品研发本职”

## 六、面试高频“大坑”及标准应答

### 坑1：你做的这个AI助理和普通客服机器人有什么区别？

> **答：** 核心区别有三点。**第一**，我们的大模型能做**意图识别和分类**，判断问题是技术类还是投诉类还是基础咨询，然后**自动分流**——这是普通固定话术机器人做不到的。**第二**，我们有**知识库自迭代**机制，人工解决新问题后系统自动提取方案录入知识库，不是靠专人维护。**第三**，我们和TTS产品深度绑定，能理解防病毒、防火墙、策略等专业场景的语义，不是泛泛的问答。

### 坑2：AI判断错了怎么办？把投诉当技术问题派给工程师？

> **答：** 我们在设计时做了**置信度兜底**。大模型在分类时会输出置信度分数，高于阈值（比如90%）才自动路由；低于阈值时**不强求AI判断**，直接归为“非标准问题”转人工。而且人工处理后的案例又会进入知识库生成流程，**误判会成为模型的迭代养料**，系统会越用越准。

### 坑3：AI自动生成的知识库文档万一错了，造成客户损失谁负责？

> **答：** 我们的流程是**“AI写初稿 + 人工终审”**。AI生成的解决方案先进入待审核池，由当班负责人或资深技术复核确认后才正式生效生效公开给客户。**AI是“草稿生成器”，人是“终审责任人”**，既保证了效率，又把控了安全底线。

### 坑4：那技术人员本来就很忙，现在还要配合审核知识库，不是增加工作量？

> **答：** 恰恰相反，这对技术人员是**减负**。过去他们每天被客服拉群问“这个问题怎么处理”，频繁打断开发。现在系统精准派单，他们**只需要在工单里回复一次解决方案**，这个回复就被自动提取入库了，**下次AI自己就会答**，不用再重复解释第二遍。长远看，他们的**打断式沟通工作量至少下降一半**。

### 坑5：你这个AI助理上线后，原来的10个客服是不是要裁员了？

> **答：** 我们的定位是**赋能，不是替代**。10个人全部保留，但工作内容发生质变——过去80%时间在回复“产品怎么安装”“防火墙怎么配”这类重复问题，现在AI全接了，他们转而做三件事：①处理情绪化投诉和复杂纠纷，②审核AI生成的知识库文档保准确性，③为VIP客户提供有温度的人性化服务。公司省掉的是 **业务增长后被迫扩招到20人** 的隐形成本。


## 七、项目陈述话术（2分钟精简版，面试开场用）

> 面试官好，我负责的项目是基于公司成熟的终端安全管理产品 **TACHYON Total Security 4.0** 进行的 **AI能力升级**。
>
> TTS本身是企业级的防病毒+防火墙统一管控平台，有完善的控制台、Agent、日志体系。这次我主导的是其中 **AI智能助理模块** 的设计和落地。
>
> 背景是客户反馈：技术服务团队规模不大（客服10人、技术6人、售后2人），高峰期排队严重，技术问题需要客服人工判断再转接，新人还得老员工带一两个月。

>
> 效果上，新人2周上岗，技术人员被打断次数减半，知识库不需要专人维护了。**同样的18人团队，能接的业务量是以前的1.5倍**。
>
> 这就是我负责的AI升级一期内容，后续还有情绪识别、主动预警、智能培训等方向在规划中。
