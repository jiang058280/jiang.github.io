## <font color="red">问题: Coze工作流有哪些常用的节点类型</font>

<details>
<summary><b style="font-size: 1.5rem; color: #2c6b8f;">👇 点击展开/折叠 面试背诵模板（建议先背这个）</b></summary>
	<mymark>
Coze工作流节点可划分为六大类：输入输出类（Start/End/Input/Output节点）、AI与模型类（LLM/知识库/意图识别/图像生成节点）、逻辑控制类（选择器/循环/批处理节点）、数据处理类（代码/变量赋值/聚合/文本处理/JSON节点）、集成通信类（插件/HTTP/数据库/工作流节点）、交互与体验类（问答/画板/会话管理节点）。Start和End是每个工作流默认必有的节点。实际搭建中，大模型节点、代码节点、选择器节点和插件节点是最高频使用的核心节点。
    </mymark>
</details>
---

### 一、输入与输出类

| 节点类型                    | 功能说明                                                     |
| --------------------------- | ------------------------------------------------------------ |
| **开始节点（Start Node）**  | 工作流的唯一入口，定义输入参数的类型（String、Number、Boolean、Array、Object、File等） |
| **结束节点（End Node）**    | 工作流的唯一出口，定义最终输出的结果                         |
| **输入节点（Input Node）**  | 在工作流运行过程中搜集用户输入                               |
| **输出节点（Output Node）** | 在执行过程中输出指定消息，可展示Loading状态                  |

### 二、AI与模型类

| 节点类型                         | 功能说明                                                     |
| -------------------------------- | ------------------------------------------------------------ |
| **大模型节点（LLM Node）**       | 调用大语言模型（豆包、DeepSeek、Kimi、GPT-4、Claude等），配置Prompt和温度参数 |
| **知识库节点（Knowledge Node）** | 从关联知识库中召回数据并返回                                 |
| **意图识别节点（Intent Node）**  | 利用大模型理解用户自然语言意图，分流到不同分支               |
| **图像生成节点**                 | 将文字转为图片，或根据参考图生成图片                         |
| **问答节点（Question Node）**    | 在对话流中主动向用户提问（按钮或输入形式）                   |

### 三、逻辑控制类

| 节点类型                              | 功能说明                                   |
| ------------------------------------- | ------------------------------------------ |
| **选择器节点（Condition / If-Else）** | 条件分支判断，相当于代码中的if-else        |
| **循环节点（Loop Node）**             | 重复执行一组任务，适合长文本分段处理等场景 |
| **批处理节点（Batch Node）**          | 循环处理列表数据或多次执行                 |

### 四、数据处理类

| 节点类型                    | 功能说明                                           |
| --------------------------- | -------------------------------------------------- |
| **代码节点（Code Node）**   | 支持Python或JavaScript编写自定义逻辑，处理复杂计算 |
| **变量赋值节点**            | 管理中间变量的赋值操作                             |
| **变量聚合节点**            | 将多个变量聚合为一个                               |
| **文本处理节点**            | 执行文本的格式化、解析等操作                       |
| **JSON序列化/反序列化节点** | 处理JSON数据的转换                                 |

### 五、集成与通信类

| 节点类型                    | 功能说明                                     |
| --------------------------- | -------------------------------------------- |
| **插件节点（Plugin Node）** | 调用Coze插件（网页搜索、图像生成、DALL·E等） |
| **HTTP请求节点**            | 通过HTTP协议发送请求到外部服务               |
| **数据库节点**              | 操作Coze数据库（SQL查询、新增、更新、删除）  |
| **工作流节点**              | 嵌套调用其他已创建的工作流，实现模块化复用   |

### 六、交互与体验类

| 节点类型         | 功能说明                                             |
| ---------------- | ---------------------------------------------------- |
| **画板节点**     | 自定义绘制的图形创作节点，用于海报、Banner等图文设计 |
| **会话管理节点** | 管理多轮对话的会话状态                               |
| **会话历史节点** | 处理对话历史记录                                     |
| **消息节点**     | 处理消息的发送与接收                                 |

---

### 搭建要点速查

- **Start和End是必有的**：每个工作流默认包含这两个节点，Start定义输入，End定义输出。
- **节点上限**：每个低代码工作流最多添加50个代码节点。
- **连线规则**：从节点右侧拖拽连线到下一个节点左侧，只有连接后才能传递数据。
- **数据引用**：下游节点可通过 `{{上游节点.输出字段}}` 格式引用上游输出。
- **异常处理**：节点运行超时或异常时，工作流会中断并返回错误，也可手动配置重试或跳转异常分支。
